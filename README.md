# ROIP Playlist

A collection of free, publicly available M3U stream playlists for online radio stations.

## ✨ Features

- Romanian radio stations (`ro.m3u`)
- Compatible with any M3U-capable media player or IPTV application

## 🚀 Usage

Open the playlist directly from its raw GitHub URL in any M3U-compatible player.

**VLC:**
```
Media > Open Network Stream > https://raw.githubusercontent.com/hmlendea/roip-playlist/master/ro.m3u
```

## ⚠️ Known Limitations

- Stream URLs are maintained on a best-effort basis and may become unavailable without notice if the broadcaster changes or removes the stream.
